# young-man-sixteen
The sixth talk to Buddha the Great Master of all gods and human beings
# ปิงคิยมาณพปุจฉา (Pingiya Manava Puccha) 🪷

> **ปุจฉาที่ ๑๖ จาก โสฬสปัญหา ปารายนวรรค สุตตนิบาต ขุททกนิกาย พระสุตตันตปิฎก**

โปรเจกต์นี้นำเสนอเนื้อหาและธรรมวิจารณ์ของ **ปิงคิยมาณพปุจฉา** ซึ่งเป็นปุจฉาสุดท้ายในหมวดโสฬสปัญหา ปุจฉานี้แสดงให้เห็นถึงความทุกข์ที่เกิดจากความชรา (สังขารที่ร่วงโรย) และหนทางหลุดพ้นที่พระพุทธองค์ทรงชี้แนะด้วยความเมตตา

---

## 📖 แก่นธรรมหลัก (Core Teachings)

ปิงคิยมาณพผู้ชราภาพ ได้ทูลขอธรรมเพื่อละความเกิดและความแก่ พระผู้มีพระภาคเจ้าทรงสอนให้พิจารณาความเป็นจริงของสังขาร ดังนี้:

1. **เห็นทุกข์จากรูป:** ทรงให้พิจารณาว่า มนุษย์ที่ประมาทมักเดือดร้อนเพราะหลงยึดติดในรูป (ร่างกายและวัตถุ) เมื่อรูปนั้นเสื่อมสลาย (แก่เจ็บตาย) จึงเป็นทุกข์
2. **ละความพอใจในรูป:** ผู้ไม่ประมาทพึงละความกำหนัดยินดีในรูปเสีย เมื่อไม่ยินดีในรูป ย่อมเป็นหนทางสู่การไม่เกิดอีก
3. **ตัดรากตัณหา:** ทรงเน้นย้ำในท้ายที่สุดว่า การถูกตัณหาครอบงำเป็นเหตุแห่งความเดือดร้อนและความชรา การละ "ตัณหา" เสียได้เด็ดขาด คือการยุติการเกิดและการแก่ชราอย่างสมบูรณ์

## 📂 โครงสร้างไฟล์ (Project Structure)

- `index.html` : หน้าเว็บที่แสดงบทสนทนาถาม-ตอบ ระหว่างปิงคิยมาณพและพระพุทธเจ้า 
  *ออกแบบ UI/UX โดยคำนึงถึงความงดงามทางศิลปะ เรียบง่าย สงบ และใช้หลัก Typography ที่เอื้อต่อการน้อมจิตพิจารณาธรรม*
- `README.md` : ไฟล์เอกสารอธิบายภาพรวมและสาระสำคัญของโปรเจกต์ (ไฟล์นี้)

## 💻 การใช้งาน (Usage)

สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ เพื่อเข้าถึงเนื้อหาพระธรรมที่จัดหน้าไว้อย่างประณีต เป็นบทสรุปแห่งโสฬสปัญหาที่เตือนสติให้ไม่ประมาทในวัยและสังขาร
